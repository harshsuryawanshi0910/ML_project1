## End To End Machine Learning Project

## Project Overview
This project aims to analyze and predict student performance in mathematics based on various socio-economic and academic factors. The analysis explores how different variables such as gender, race/ethnicity, parental education, lunch type, and test preparation course influence student scores in math, reading, and writing.

## Problem Statement
Understanding the factors that influence student performance is crucial for educators and policymakers. This project addresses the following questions:

What factors most significantly impact a student's math score?

How do demographic and socio-economic factors correlate with academic performance?

Can we build an accurate predictive model to estimate a student's math score based on given features?

## Dataset
The dataset used in this project is the Students Performance Dataset from Kaggle, containing 1000 entries with the following features:

gender: Gender of the student (male/female)

race/ethnicity: Ethnic group (Group A, B, C, D, E)

parental level of education: Highest education level of parents

lunch: Type of lunch (standard/free/reduced)

test preparation course: Whether the student completed the test preparation course

math score: Score in mathematics (target variable)

reading score: Score in reading

writing score: Score in writing

##  Exploratory Data Analysis (EDA)
Key insights from the EDA:

Demographic Insights:
The dataset has a balanced gender distribution (52% male, 48% female)

Most students belong to Group C and Group D

Largest number of parents have "some college" education

Performance Insights:
Gender: Female students perform better in reading and writing, while males excel in mathematics

Race/Ethnicity: Group E students score highest overall; Group A students score lowest

Parental Education: Higher parental education correlates with better student performance

Lunch Type: Students with standard lunch perform significantly better than those with free/reduced lunch

Test Preparation: Students who completed test preparation courses score higher across all subjects
